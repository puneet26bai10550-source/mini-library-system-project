# Mini Library System

This is my beginner Python project! It is a simple command-line application designed to manage a small library. You can add new books, view all books, search for books by title, and issue or return them using their Book ID.

---

## Tech Stack & Features

* **Programming Language:** Python 3
* **Data Structure Used:** List of Dictionaries

### Main Features:
* **View Books:** Shows all books in the system along with their current status (`Available` or `Issued`).
* **Add Book:** Add custom books to the library collection.
* **Find Book:** Search for any book by typing a title or keyword.
* **Issue Book:** Mark a book as issued so nobody else can take it.
* **Return Book:** Mark an issued book as returned back to the library.

---

## How to Run the Program

1. Make sure you have **Python 3** installed on your computer.
2. Download or copy the code into a file named `library.py`.
3. Open your Terminal or Command Prompt.
4. Run the program using the following command:

```bash
python library.py
